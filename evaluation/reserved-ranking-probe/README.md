# Frozen mixed-language candidate-ordering probe

`corpus.json` contains 60 synthetic cases: ten each English, Nepali, mixed, ambiguity, personal-name and literal/technical text. The fixture was authored separately without running or inspecting Lekha's outputs. The accompanying generator constructs only this reference JSON; it does not import the engine. Do not provide the cases to an implementation author before their candidate and evaluator are frozen.

These sentences were AI-authored with project/conversation context, not sampled from real users, and no Nepali speaker reviewed the intended spellings, word boundaries, name handling, or translations. They are not an independent or representative population accuracy sample. The ambiguity category explicitly encodes one possible intent; especially in mixed text, other intents may be valid. English-labeled proper names are preservation controls, not a claim that names belong to English.

Each case includes one or more full proposed outputs and **selective, ordered** token annotations. Unannotated words should not be scored or assigned a role automatically. Labels are `english`, `nepali`, and `literal`; for `literal` compare the unchanged exact span. Some emoji or other spans are not word tokens, so a containment-only fallback must be labeled as such and cannot prove position or host safety. Punctuation is part of sentence exact matching. Full-reference alternatives may still omit valid variants, spacing or morphological choices. Report candidate recall, top choice, original preservation and category denominators separately; do not equate availability with correct automatic selection or actual user outcomes.

Before scoring, record source, index, evaluator and fixture hashes. The first result spends this fixture: do not tune on it and then call it untouched. This probe does not exercise UI, IME lifecycle, host insertion, focus, privacy, latency or accessibility. No software or input source was installed or enabled.
