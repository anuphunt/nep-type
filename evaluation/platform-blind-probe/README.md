# Blind cross-platform mixed-language fixture

`corpus.json` has 55 synthetic cases: 11 each for English, Romanized Nepali, mixed English–Nepali, ambiguity and literal text. A separate agent authored and froze these references without running either engine, reading outputs, or sharing examples with the Android development agent. Corpus SHA-256: `9fdf89737a7a5a77470a8b7fdea64a6ba6592366abae418117b113721c658720`.

This is **not** a representative user sample or independently validated ground truth: it is AI-authored, conversation-informed, and unreviewed by Nepali speakers. Roman spellings and borrowed words may represent multiple intentions. Annotation `acceptable` values contain some alternatives but are not exhaustive; full-sentence `expected` usually lists only one, and joining or separating particles and punctuation may vary. Exact-string scores can understate reasonable output. Distinguish automatic top choice, explicit candidate availability, and original preservation, rather than equating these or using all candidates as automatic accuracy.

The shape follows the prior frozen probe: each case has `id`, `category`, `split`, `source`, `input`, `expected`, and ordered **selective** annotations with `token`, `role` (`english`, `nepali`, `literal`) and `acceptable`. Skipped input tokens must not be assigned a role by inference. Some literal spans (emoji and digits) are not engine word tokens; if scored by substring containment, state that this does not verify host position or selection. A reviewer should identify and report any evaluator/fixture mismatch rather than silently excluding it. No host, key events, focus, privacy, performance or text-safety behavior is tested by this fixture alone.

`generate.py` reproducibly writes the fixture and checks annotations appear in the input in order. It does not load the project, invoke an engine or read engine output. Freeze the baseline, candidate and evaluator hashes before a single comparison; the results consume this probe and it must not be described as untouched for later tuning.
