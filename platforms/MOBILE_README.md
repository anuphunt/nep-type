# NepType mobile experimental projects

The iOS project now builds an offline Nepali candidate keyboard with a snapshot of NepType's engine. See [iOS README](ios/README.md) for behavior, synchronization, build results, limitations and unverified host safety. Android remains a literal-only, uncompiled input-method shell; see the [Android project](android/). Neither is ready for production or real use. No keyboard has been installed or enabled.
