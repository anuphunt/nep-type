## Configure before enabling measurement

- Use standard GA4 and the Google tag. No Tag Manager, measurement-protocol secrets, paid services, advertising links or new credentials are needed.
- Disable all stream enhanced measurement, including history-based pageviews, search, form interaction, scroll, outbound link, file and video events. Record the configured state. Keep Google Signals and advertising personalization off and do not add cross-product links.
- Set only the verified public web-stream ID in `PUBLIC_GA_MEASUREMENT_ID`. This ID is not a credential. An empty value leaves Google measurement inactive; malformed values fail the build.
- Configure the existing public PostHog token and host together if retaining website action measurement. Website PostHog now also requires affirmative consent and uses page-memory identity. Its previous persistent-browser unique counts form a different baseline.

## Implemented controls

The website loads no Google tag or provider request before opt-in. Bilingual controls offer Allow, Decline and settings/revoke from the footer and privacy page. DNT/GPC, existing opt-outs, blocked storage and cross-tab revocation are handled. Revoke does not reload or discard a typing draft. Requests already in flight can finish.

Google receives a manual pageview for a generated public path, a fixed title and only a reviewed search-engine origin. Arbitrary paths become `/404/`; query strings, fragments, unknown referrers, campaign parameters, typed text, clipboard data, forms and search terms are excluded. Google advertising storage/personalization remains denied. Standard consented session/engagement events may also be generated by the actual Google library. Actual library behavior still needs payload verification for the real configured stream.

PostHog keeps only reviewed event names, coarse fixed values, transport-required public token/random ID and minimal browser/device metadata. Person profiles, automatic capture, recording, remote features and batching are off. SDK top-level profile updates are dropped. Its identity and event metadata remain in page memory; no queued pre-consent or revoked actions are replayed. Native-app analytics is unchanged.

These controls are implementation details, not a claim of legal compliance.
